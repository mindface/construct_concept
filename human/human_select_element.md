## 選択における構成要素のプロトタイプ

情報の選択構造において、選択の対象構造の認知と選択範囲の
無意識の形成レベルの構造や対象に対する目的達成範囲の規定内容が存在しています。
選択の構成要素に対して仮説を説明している。

これは心理的要因を含めるので、言語の抽象性から実態を厳密かする処理の構成を把握した上で、個人の形成されている意識上の処理と無意識の情報を再構成する前提で形成されている。

#### 関連タグ
学習工程、無意識


#### 仕様
情報を選択する構成要素のプロトタイプを提供している。

#### 継承対象
選択における最適化


##### 目的
無意識におけるプロトタイプの提供におけるデータ収集や
別の理論構築から更新あるは別の理論定義としてのアクセス因子と利用することを目的としている。

脳のスパイク現象や記憶の構造、神経における白質など含めた


##### 前提
意識下から無意識に影響する範囲を観測できる。
この場合おいて、無意識の制御は目的としていない。
結果的に影響している範囲を情報化することから、使えることを判別する規定することをベースにとられる。


##### 思考する対象
認知したシンボルや言語情報から構成される無意識で意識できないが情報化されている範囲を対象としている。

メソッドに関しては無意識の範囲を情報として使うことをベースにしている。

### 詳細
選択における対象を認知して、目的と選択候補を考慮する。
この場合における目的の設定と選択候補は、初期値と選択のおける情報量が増えることで選択構造における評価が徐々に変化していく。

要素は抽象的には以下になる。
- 時間
- 得られる報酬
- 過去情報からのオペレーション(別の目的に使うための情報化)
- 思考するコスト
fn(n) 目的に応じた情報や対象追加

意識から影響する範囲を規定して、ツール可能な範囲における再現性を確認することで選択の対象と無意識から構成される内容に影響を与える。無意識には影響範囲があるの制御は連動範囲を自覚していないため、この場合は安定させていることが推察される。

意識上の仮説と安定性から無意識における情報の定義をすることができるので、そこから細分化構造の機能として指標化することができる。

注意に対象の言語から構成される無意識の情報のレベライズがあり、以下のような分岐があるときにlの刺激を含めて以下の存在があり結果は[a',b',c']となる。

target Lang => l
  l-a-a' 
    b-b'
      |
      c - c'

bの先に定義してbb -> bb'
を意識的に注意した場合に以下の構成に変化する。

target Lang => l
  l-a-a' 
    b-b' - bb -> bb'
      |
      c - c'

無意識の出力される結果を考慮するのであり、抽出される。
ただ、lの構成がaから連動してaという要因を規定された場合に以下のようになる。

target Lang => al
  al-aa-aa' 
     ab-ab' - abb -> abb'
        |
        ac - ac'


構造的なプロダクトで椅子のデザインや構造である時にコンセプトを加えて、素材の構成として全体が派生して変化する。
椅子であれば、表面が皮素材を加えるaとポリエステルを含めた化学素材のbで価格やコストの連動処理が走る。

鉄加工であれば、対象の素材から経験に紐づく[a,b,c]を加えて合金などの加工技術に昇華して、同じ形状は組み合わせに対する情報量を保持してくことのイメージ構造として定義する。

デバイスの部品における加工プロセスにおいて、対象の作業で利用されている化学製品における価格の変化や目的となる性能が上がることから変更することによってから加工する候補が[a',b',c']という結果になることに定義する。

アプリケーションでかくパールのデザインが印象的な柔らかい場合は丸角とパステルカラーを構図的に適用される

システムで使われる対象スキーマの各対象のエリアで加わる情報によって構成概念のプロダクトの構図が必要なニーズにおいて継承レベルで変化することを示していくことが考えられる。
例えば、鉄の標準分子形状におけるスキーマの情報に対して
各時点で加工と加わる情報構造によって基本オブジェクトの構成が変化していく。

この無意識の連動に関しての情報の構成に関してはいくつか
この構成要素の妥当性を資格やテストの工程から無意識における情報の出力平均化をはかり情報の標準出力として使っていく。
記憶した構成を加工して使う場合の連動の場合に応用可能であれば情報を使うことが考えられるが、仮説的な認知処理を言語で定義する場合に制約条件の前提を示していることはこれらの連動した処理の規定があるためになる。
